# 运行中作业的生存尾部估计实验

结论：**不采用**。仅在 train 16 场景验证；未查看 holdout、未修改 main.cpp / submit.cpp、未进行网页提交。最佳固定变种总利润仅 +0.323%，8 胜 8 负，未建立跨场景至少 1% 的稳定收益证据。

基准为 results/final_train（84 分版本）。待运行作业的估计时长与租户学习模型保持原样，只修改 estimate_duration 中已经运行的作业。

令 d 为原估计时长，a 为扣除准备时间后的运行时长。原尾部下界为 0.25*d；线性变种改为 0.25*d + alpha*max(0,a-threshold*d)。饱和变种增加 alpha*d*overrun/(d+overrun)。准备期 a<0 的规则不变。

最佳固定候选：candidates/v2_duration_late150.cpp，其规则是 `0.25*d + max(0,a-1.5*d)`。逐场景利润与可调环境版 late150a100 完全一致；固定源码另行编译并完整跑过 train 16。所有已运行场景均 0 对账错误、0 非法指令。

固定候选总利润 52574889 → 52744481。它改善部分慢时长场景，其他场景有回撤，收益幅度不足以支持替换现有84分版本。

alpha=0 的控制变种在 small_01 与 standard_00 两场景精确复现基准利润。变种均只添加常数次算术，但本轮并发运行与 Windows 进程计时会使 CPU 结果波动，不能把观测时间差当作严格性能结论。
