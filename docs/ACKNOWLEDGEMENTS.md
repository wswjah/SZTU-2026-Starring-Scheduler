# 致谢与来源

感谢愿意公开代码、分析和迭代记录的同学。这个项目能较快进入可验证的探索，首先依靠的是两份已经完成大量工作的公开程序。它们是整体路线的基石，后续的正式成绩不能只用本项目的版本号来讲述。

## Misuzu0010：早期81分基底

上游仓库：[Misuzu0010/SZTU-2026-data-structure-final-homework](https://github.com/Misuzu0010/SZTU-2026-data-structure-final-homework)。

早期路线从该仓库公开的81分程序、阅读版及策略分析开始。它提供了交互、状态维护、计费对账和流程调度的可工作基础，让本项目可以直接围绕输入局部性、时长尾部、估价与性能做对照实验，逐步得到正式84/85分，并继续V4、V5的独立探索。

这里的81分是上游作者公开报告的历史成绩；本项目没有把它写成自己重新测得的正式分数。早期引用文件的指纹与来源记录在[V1清单](../versions/v1_84/manifest.json)，来源和派生关系继续在公开文档中记录。

## Shuang-su：后期96分基底

上游仓库：[Shuang-su/SZTU-2026-data-structure-final-homework](https://github.com/Shuang-su/SZTU-2026-data-structure-final-homework)。本项目采用的固定commit为[`a35a23f3a8a3c623ff9c62af15e680143264de5e`](https://github.com/Shuang-su/SZTU-2026-data-structure-final-homework/tree/a35a23f3a8a3c623ff9c62af15e680143264de5e)。

后期路线以这份96分程序为主体。整流程五情景收益预测、在线租户时长学习、同tick镜像预热、忙机器预约、止损，以及高效的对账状态维护，构成了96→99分和后续V9—V15研究的基础。

V6在该主体上修复后继scratch数组边界、每tick指令预算、预热原子性和延后终止，正式测得96分。之后加入末tick清理并有限调参，V8正式测得99分。由于基底和多项改动共同影响调度轨迹，不能把某几个百分点分配给单独一处修复，也不能把99分主体算法称为本项目从零原创。改动边界见[V6审查](../research/v6_attributed96_review.md)和[V8实验](../research/v8_experiment.md)。

## 本项目继续做了什么

在两份公开工作的基础上，本项目保留了本地生成场景、同输入比较、正式提交回执、源码指纹，以及没有晋升的方向。主要后续工作包括边界与命令预算修复、性能控制实验、有限参数筛选、告警风险预测、精确LRU与更宽搜索、真实双顺序试跑、首次接纳的小树与神经网络、扩训及独立数值核验。

这些工作也有清楚的失败结果：V4本地收益没有增加正式分数，V9风险选机未带来训练净收益，多项更费计算的搜索退步，V15扩训网络正式98分，未超过V8的99分。完整过程见[实验历程](EXPERIMENT_JOURNEY.md)，相应阶段报告保留了比较口径和局限。

也感谢课程提供的题目、样例与本地评测工具，使计费、对账和合法性能够被实际检验。公开仓库不分发评测机二进制，使用者需自行取得合法副本。
