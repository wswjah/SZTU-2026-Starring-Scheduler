# 公开归档说明

这是本地研究工作区的筛选公开副本。包含各版源码、候选方案、实验工具、合成参数、结果摘要、训练模型参数及独立审查；原始逐tick日志、运行目录副本、大型CSV/NPZ、编译产物、认证/提交脚本和课程评测机不随仓库发布。

用户要求移走自有派生代码开头的四行说明，来源集中记录在README和ACKNOWLEDGEMENTS。每份处理过的C++文件都已验证预处理token序列与本地原件相同；正式提交原件留存本地。PUBLICATION_MANIFEST.json分列original_sha256与published_sha256。历史实验中记录的源码、元数据、运行程序HASH仍指向当时的原件，不会伪装成公开副本的HASH。

JSON/文档中的本机路径和个人字段已去除或改为相对路径。结果中的环境字段、路径、部分响应结构经过处理，所以它们本身的字节HASH可能改变；原始与公开文件指纹均在导出清单中。版本与实验名、种子、利润、计费、对账、非法指令、模型权重等研究内容保留。

cases下是本地合成配置，不是官方隐藏测试。课程题面、原生样例和本地评测程序请从课程平台自行取得；将tpj_win.exe放在仓库根目录后，可以使用tools/bench.py。默认编译和新建输出目录的本地评测可直接使用；历史脚本保留了当时的冻结HASH与“禁止覆盖已有输出”的保护，完整重建某轮需要按实验报告先生成缺失数据，并使用独立输出目录或新工作副本，不能保证所有历史pipeline一键重放。
